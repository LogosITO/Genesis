# Simulation time and determinism

`SimulationStep` is a finite positive duration in seconds. `SimulationTime` counts completed steps as `u64`; no wall clock participates. The original `advance` path updates each ordinary sphere radius as `radius + growth_per_second × step_seconds`. The First Life `advance_life` path first applies that tick's typed world events, including pruning, then samples sources, proposes organism growth, and advances ordinary radii. It clones the world and commits both world and tick only after every phase succeeds. Tick overflow, invalid event, or invalid proposal leaves both unchanged. See [replay ordering](replay-determinism.md).

For identical initial state, queued events, step, executable, and floating point environment, the same ordered operations yield repeatable results. Floating point rounding accumulates over steps; arbitrary target platforms and compiler settings are not promised bitwise identical. The seed is reserved for future explicitly seeded rules; there is no stochastic behavior in this slice.
