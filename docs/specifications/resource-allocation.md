# Finite resource allocation (Foundation 0.8)

**Status:** experimental deterministic model, not biological energy transport. All quantities below are model resource units unless stated otherwise.

## Influence and demand

A finite `ResourceSource` retains the pre-existing analytic influence function `R_s(p) = strength_s × max(0, 1 − |p − centre_s| / radius_s)` while enabled. `R_s(p)` is a dimensionless spatial weight; evaluating it does not consume stock. A disabled source has zero influence but continues replenishing. Sources have stable world IDs, `stored ∈ [0, capacity]`, capacity `(0, 1_000_000]`, and nonnegative replenishment offered once per fixed tick, at most `capacity`. At tick start, actual generation is `min(capacity − stored, replenish_per_tick)`. Only actual generation enters `total_replenished`; clipped offers do not.

For organism *o*, active node *i*, source *s*, and fixed duration `Δt`, the local request is `q_{ois} = R_s(p_i) × uptake_o × Δt`. A saturated node requests zero. The organism requests `d_{os} = max_i q_{ois}` from that source. The maximum preserves the previous growth model's rule that additional tips do not multiply the same source's supply. Before source competition, all of one organism's demands are scaled by `min(1, headroom_o / Σ_s d_{os})`, where `headroom_o = 48 × threshold_o − budget_o`. Thus the finite reservoir is not charged for units that cannot enter the bounded shared budget.

For each source, let `A_s` be its stored units after replenishment and `D_s = Σ_o d_{os}`. If `D_s > 0`, the nominal allocation is `a_{os} = d_{os} × min(1, A_s / D_s)`. Organisms are visited in stable insertion order and each withdrawal is clamped to the remaining stock; this only resolves floating-point residue, not a policy preference. Every withdrawal reduces source stock and increases `last_allocated` and `total_allocated`. The real-arithmetic invariant is `Σ_o a_{os} ≤ A_s`; no withdrawal can make stored stock negative. A sum of separately rounded withdrawals in `last_allocated` can exceed capacity by an ulp; validation permits a relative margin of `16 × f64::EPSILON` for such residue. Exact decimal equality is not promised with `f64`.

The organism's spendable budget gains `Σ_s a_{os}`. Each active node receives a maturity signal `g_{oi} = Σ_s q_{ois} × a_{os} / max_i q_{ois}`, with zero contribution for a zero source demand. Maturity signals are not additional resource units and must not be summed as a conserved energy balance. Growth consumes one threshold from the spendable budget per child, using existing node-ID order. Existing node energy is a bounded readiness signal. Pruning loses readiness stored on removed nodes and does not refund prior source consumption. A full node graph or exhausted lifetime allocator does not silently create new nodes.

The reservoir ledger records initial stock, cumulative actual replenishment, cumulative allocation, current stock, and last-tick values. In real arithmetic, `current = initial + total_replenished − total_allocated`. Version-5 save validation retains its established practical allowance of `1e−10 × (1 + total_replenished + total_allocated)` model units so older valid saves are not rejected by a tighter policy. This is not a formal error certificate for arbitrarily many ticks. A 2000-tick four-organism regression independently enforces the much tighter `512 × f64::EPSILON × (1 + total_replenished + total_allocated)` bound at every tick; its observed maximum residual was `3.54e−12` on the recorded Windows run. Invalid, nonfinite, or overdrawn states fail validation; a tick commits only after the entire proposed world succeeds. See [reliability measurements](../research/world-reliability-experiment.md).

## Ordering and compatibility

At each tick: clone prior world; apply ordered source, pruning, and body-input events; replenish every finite source; sample current surviving tips; collect all organism/source demands; allocate each source proportionally; mature nodes and propose growth; advance ordinary spheres; sweep the body against the resulting geometry; validate and commit world and integer tick. Newborn nodes request resources starting next tick. Source movement or disabling affects this tick's demands. Contact geometry is compared with the authoritative post-growth world and the BVH is rebuilt only when a collider changes.

`spawn_source` retains the pre-0.8 unlimited, nonconserved field model for old examples and saves. `spawn_finite_source` opts into finite accounting. One world cannot mix finite and unlimited sources; such a world fails explicitly. A finite source with zero stored units and zero replenishment cannot fund new growth. A disabled source can refill to capacity but allocates zero. Version-5 saves retain all ledger fields; versions 1–4 load their sources as unlimited.

## Limits and open questions

The policy is proportional to maximum local demand, so it avoids large insertion-order bias but is not a physical transport equation. Separate sources can feed the same organism; maturity signals may overlap spatially, while the spendable budget only receives allocated units. Floating-point rounding and capacity clipping are visible in ledgers. The model has no diffusion, shading, uptake inhibition by other structures, competition for space, recycling, reproduction, or cross-platform bitwise guarantee. Whether the rule produces useful emergent morphology is a research question, not an established finding.
