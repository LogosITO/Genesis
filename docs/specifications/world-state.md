# World state

`WorldState` stores ordinary analytic growing spheres, growth organisms, and resource sources in insertion order. `EntityId` is a shared monotonically assigned `u64`, stable for the world's lifetime and never reused. Each ordinary entity owns a `Sphere`, `Transform`, and nonnegative finite growth rate. Each organism owns stable local node IDs and parent links; each source owns a continuous concentration field. Removal, component systems, and general object types are not implemented. Invalid insertion leaves the world unchanged. `DeterministicSeed` is recorded in state; current rules do not consume randomness, so changing the seed does not change outcomes.

The world exposes read-only access to entities, organisms, and sources. Controlled organism growth and source mutation preserve invariants. The simulation copies the world, validates proposed changes, and commits atomically. Versioned persistence belongs to `world-runtime`; direct deserialization into `WorldState` must be followed by `validate()` before use. See [growth](growth-model.md), [environment](environment-fields.md), and [persistence](world-persistence.md). This is a minimal state model, not a general ECS.
