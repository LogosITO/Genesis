# Bounded ecosystem state (Foundation 0.8)

`WorldState` remains the sole authority for up to four ordered organisms, four resource sources, 48 active nodes and 1024 lifetime node IDs per organism, the optional kinematic body, and ordinary analytic spheres. Organism world IDs and local node IDs remain stable; pruning creates gaps and never reuses them. Each organism owns its root, growth parameters, ordered nodes, maturity signals, shared spendable budget, and lifetime ID allocator. `OrganismLifecycle` is derived independently for each organism: `Active` when another structural child is possible, `Saturated` when active topology cannot add a child, and `Exhausted` when lifetime IDs are spent. Scarcity can stop an `Active` organism without changing its structural lifecycle.

Finite source state includes analytic position/radius/strength, active flag, current stock, capacity, per-tick refill, initial stock, last and cumulative actual replenishment, and last and cumulative allocation. These values are validated on load. There is no voxel grid or renderer-owned ecological state. Renderer snapshots copy current analytic spheres and capsules with stable semantic targets; organism colors distinguish the four bounded identities in insertion order. Source-marker position and active state are authoritative; its visual size is a marker, not the radius of a physical resource volume.

`Runtime` records fixed step, completed tick, world, and ordered future events. Version 5 adds finite reservoir state while keeping versions 1–4 readable as unlimited-source worlds. A finite source mislabeled as an older format is rejected. `load_into` leaves an existing runtime unchanged on error. Replay equivalence is tested within the same build and floating-point execution model; bitwise equivalence across arbitrary platforms is not claimed.

Pruning applies before demand collection, so removed tips cannot request resource on that tick. New growth enters the contact and render snapshots after allocation and growth. A branch that grows into the kinematic body reports initial overlap without teleporting it; full collision resolution is outside this milestone. Contact BVH rebuilding on every body tick is correct but has not been optimized for unchanged geometry.
