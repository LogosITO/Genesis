# World reliability experiment (Foundation 0.8.1)

**Status:** local engineering measurement on Windows, AMD Ryzen 5 7500F, Rust 1.94.0, release profile. This is not a cross-platform or formal numerical certification.

## Established knowledge and decision

The authoritative world owns analytic spheres, growth-node spheres, and connection capsules. The contact BVH stores only conservative bounds and references into a derived solid snapshot. Direct contact traversal remains the reference. Existing saves contain world, time, and event state; no BVH is authoritative.

The prior implementation built a contact BVH on every body tick. A pre-change 50-repetition release benchmark measured a median rebuild of 0.0601 ms against a 0.0019 ms accelerated query for the 380-solid scene. We therefore kept one disposable `ContactScene` in the runtime and native viewport. Every body tick gathers validated solids and compares exact IDs and geometry with the cached snapshot. An equal snapshot reuses the BVH; any changed collider triggers a full rebuild. Resource stock, source state, body position, and camera state are excluded because they do not describe static obstacles. Load starts with an empty cache. No geometry revision is serialized, and no incremental refit was added.

## Correctness observations

The cache regression changes finite source balance and position and moves the body without rebuilding, then grows, prunes, adds an ordinary sphere, and changes its radius with expected rebuilds. A save/load continuation starts with no cache. The direct and BVH paths agree on 1024 deterministic dense-scene sweeps and 2048 sweeps through the 380-solid scene. Independent analytic cases check sphere entry fraction and normal, capsule side entry, initial overlap, a surface start moving inward or outward, degenerate capsules, near-tangent classification, high-speed movement, and nearest stable identity. The narrow phase is shared by direct and BVH paths, so differential tests alone cannot certify its mathematics. Near-tangent roots within the documented heuristic uncertainty window may return `Indeterminate`; they are never intentionally downgraded to `Miss`. Overlapping branch solids remain independent colliders, not a regularized union.

A headless end-to-end test grows two organisms from one finite source, picks connection child 1 from a CPU analytic ray, and compares pruned/unpruned one-tick probes to confirm that the cut changes both organisms' resource budgets before any source-disable event. It then prunes that stable target, confirms its authoritative and snapshot removal, checks direct/BVH contact is cleared, moves the kinematic body across the path, resumes source-driven growth, saves, reloads, and compares final save bytes. Three further 240-tick scenarios use seeds 13, 38, and 80 to choose different source movement, pruning, and body-input event sequences across four organisms. Each tick checks world validity, stable node-ID progression, an empty consumed-event queue, the resource ledger, direct/BVH contact, bounded snapshot size, and bounded save size. All three saved continuations match uninterrupted state exactly in this build. The seed itself does not randomize growth; it selects the test event sequence.

For the existing 2000-tick four-organism finite-resource fixture, the maximum observed conservation residual `|initial + actual replenishment − actual allocation − stored|` was `3.5356717553725048e−12` model units. The test now enforces `512 × f64::EPSILON × (1 + cumulative replenishment + cumulative allocation)` at every tick, much stricter than the established version-5 save validator's `1e−10` multiplier. The save validator was deliberately left unchanged to avoid rejecting previously valid long-running saves. The stricter regression is an empirical guard against large or systematic drift in this fixture, not an unlimited-time bound. Zero supply, oversubscription, disabled sources, capacity clipping, pruning, and save/load also have focused tests in the earlier ecology suite.

## Limitations and open questions

The release native viewport smoke-launched for four seconds on the same GPU, reached tick 46 at 1280 × 720, and printed one status sample of 64.9 FPS, 0.33 ms CPU submit, and 0.028 ms GPU compute with 16 primitives. It was a hidden window and not a controlled latency experiment. The native click → semantic selection → P → I/J/K/L → pause/resume sequence still needs a real interactive session. The headless pick and mutation test does not substitute for pointer coordinates, focus changes, or visual inspection of the live window. GPU rendering code and analytic snapshots were not changed. The cache has no published hit counter and its full-tick gain is workload-specific. The `64 × EPSILON` root-discriminant uncertainty heuristic, save-validation allowance, and stricter ledger regression bound are practical policies, not proven complete error bounds. Contact between overlapping branch seams and precise penetration depth remain open numerical research questions. Cross-platform bitwise replay and indefinite stability are unverified.
