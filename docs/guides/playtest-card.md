# The Passage — playtest card

**Experimental build.** This is a short local game. No account or network is needed. Your feedback is more useful than a perfect playthrough.

## Goal

Move the **orange player** through the blue-walled lane to the **magenta goal**. The **green growth** obstructs the route. The **yellow source** feeds the two growing structures. The overlay shows whether the source is near or away and whether the central stem still blocks the route.

## Controls

| Key | Action |
| --- | --- |
| W/A/S/D | Move the orange player |
| Arrow keys | Change camera angle |
| Left click | Select a visible node or connection |
| P | Cut the selected non-root branch |
| M | Move the yellow source |
| O | Switch its resource input on or off |
| Space | Pause or resume |
| R | Restart |
| Esc | Exit |

Start with `PLAY.cmd`. If the window does not open, keep the error message and note your Windows version, GPU, and driver in `FEEDBACK.md`. A Vulkan or DirectX 12 GPU and driver are required. The package contains the executable and needs neither Rust nor Cargo. If you get stuck, describe what you tried before reading `GUIDE.md`; that helps us improve the in-game explanation.
