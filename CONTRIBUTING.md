# Contributing

This is an experimental research project. Before a change, read the [architecture](docs/architecture/overview.md) and relevant ADR. Keep analytic state authoritative; do not add renderer dependencies to core crates. Describe the mathematical contract, tests, limitations, and reproduction steps in a pull request. Run the four checks in the root README. Use the [experiment template](docs/research/experiment-template.md) for performance or numerical claims. Avoid speculative crates and dependencies. Contributions are offered under MIT OR Apache-2.0.
